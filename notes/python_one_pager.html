01 Your starting point

import numpy as np
import matplotlib.pyplot as plt

values = np.array([1, -1, 2, -2, 3])
doubled = values * 2
average = values.mean()

Result: [2, -2, 4, -4, 6]; mean: 0.6.

Array, not list. [1, 2] * 2 repeats a list. np.array([1, 2]) * 2 doubles its values.

plt.ylabel("sin(x squared)")
plt.show()

05 Three rules worth remembering

Index from zero. Call with parentheses.
values[0] selects; np.mean(values) calls a function. Python uses indentation to group code.
Division already works in Python 3.
3 / 5 = 0.6; 3 // 5 = 0; -3 // 5 = -1. // floors toward negative infinity. No __future__ import needed.
Match dimensions before multiplying.
For 2D arrays: (rows, inner) @ (inner, cols) gives (rows, cols). Unexpected result? Check .shape and broadcasting.

06 Load course data safely

import pickle

with open("course_data.pkl", "rb") as data_file:
    data = pickle.load(data_file)

rb = read binary. with closes the file automatically. pickle is included in Python.

Trusted files only. A pickle can execute code while loading. Do not open unknown downloads with pickle.load.

Legacy Python 2 data with decoding errors may need pickle.load(data_file, encoding="latin1"). Use only when required for compatibility.
